# Aether Launcher

Refined. Adaptive. Reliable.

Package: `com.aethlauncher.kyn` | Min SDK 26 | Target SDK 36

## Status (2.0.0-rc1)
- M0 Project Foundation
- M1 Safety Core (crash recovery, Emergency Exit, Safe Mode)
- M2 Home Screen & Visual Engine
- Liquid Glass asli (wallpaper blur), animasi pegas, drag-and-drop, dock editor
- App Drawer (pencarian, kategori otomatis + kustom, urutan)
- Gestur, Hidden Apps, App Lock (PIN), pengaturan per kategori

## Belum ada
Icon pack, notification badge, double tap to sleep, double icon dock, folder di Home,
biometrik, AppWidget hosting, signing release.

## Build
Push ke branch `main` atau jalankan workflow "Build APK" dari tab Actions.
APK debug ada di Artifacts: `AetherLauncher-debug`.
